# QCSchema — Quantum Chemistry Schema

The core qcschema package.

## Directory structure

### `data/` — Generated JSON Schema documents
Contains the generated JSON Schema files for all schema versions.

- **`v1/`** — v1 JSON Schema documents (draft-04, frozen)
  - Generated by `qcschema/v1/generate.py`
  - `qc_schema_input.schema` — Input specification
  - `qc_schema_molecule.schema` — Molecule structure
  - `qc_schema_output.schema` — Output specification

- **`v2/`** — v1.5 enhanced JSON Schema documents (draft-04, frozen)
  - Generated by `qcschema/v1_5/generate.py`
  - Same three schema files as v1, with wavefunction support
  - Version number: 2 (v1.5 is the v2 JSON Schema version)

- **`qcelemental_v1/` and `qcelemental_v2/`** — Companion schema directories (dev-only)
  - Will contain JSON Schema representations of qcelemental's pydantic models
  - Generated by scripts in their respective directories (not shipped)

### `v1/` — v1 schema generator
Modular generator for v1 JSON Schema documents.

- **`generate.py`** — Main entry point: `python -m qcschema.v1.generate`
- **`generator/`** — Schema component modules (source of truth)
  - `molecule.py` — Molecule schema definition
  - `definitions.py` — Shared definitions (provenance, error, basis, etc.)
  - `basis.py` — Basis set specifications
  - `properties/` — Output property definitions

### `v1_5/` — v1.5 schema generator
Modular generator for v1.5 (v2) JSON Schema documents. Inherits from v1 and adds wavefunction.

- **`generate.py`** — Main entry point: `python -m qcschema.v1_5.generate`
  - Imports and extends `qcschema.v1.generate.build_v1_schemas()`
  - Adds wavefunction support to output schema
  - Updates version number to 2
- **`generator/`** — v1.5-specific additions
  - `wavefunction/` — Wavefunction schema definitions

### `qcelemental_v1/` and `qcelemental_v2/` (future)
Placeholders for qcelemental companion schema generation scripts.

## Version naming

- **v1**: Original QCSchema (version: 1)
  - Frozen, JSON Schema draft-04
- **v1.5 / v2**: Enhanced QCSchema (version: 2)
  - Adds wavefunction support
  - Frozen, JSON Schema draft-04
  - Called "v1.5" in directory names, "v2" in version numbers
- **Pydantic v2 API** (future): Separate Python object layer
  - Will be built on pydantic v2
  - Uses JSON Schema 2020-12

## How schemas are generated

Schemas are not hand-edited. To regenerate:

```bash
# Generate v1 schemas to qcschema/data/v1/
python -m qcschema.v1.generate

# Generate v1.5 schemas to qcschema/data/v2/
python -m qcschema.v1_5.generate
```

The generators use modular component files in their respective `generator/` subdirectories. v1.5 inherits from v1 and extends it with wavefunction support.
v1.5 is the longstanding state of the QCSchema repo from 2020-2026.

## Public API

See `validate.py` and `versions.py` for the main entry points:
- `qcschema.get_schema(schema_type, version)` — Load a schema
- `qcschema.validate(data, schema_type, version)` — Validate an instance

## Notes

- v1 and v1.5 schemas are frozen and protected (GOAL.md)
- Schema files are minified JSON (single-line format)
- Companion qcelemental schema generation is dev-only (not shipped)
